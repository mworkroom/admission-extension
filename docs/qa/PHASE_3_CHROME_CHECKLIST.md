# Phase 3 실제 Chrome 수동 검증 체크리스트

## 목적

P3-6에서 자동화가 직접 읽을 수 없는 Chrome Side Panel의 실사용 동작을 확인한다.

이 문서는 실제 Chrome 확인 결과를 기록하기 위한 체크리스트다. 체크하지 않은 항목은 완료로 간주하지 않는다.

## 사전 조건

- Chrome 기본 프로필에서 압축 해제 확장 `Admission Checklist`가 버전 `0.7.1`으로 로드되어 있다.
- KCL, SOAS, QMUL 과정 페이지를 각각 열 수 있다.
- 초기 분석 기준은 `2026/27 · 2026년 9월 · Full-time · International`이다.
- 테스트 중 저장하는 확인한 사항은 Chrome 기본 프로필의 `chrome.storage.local`에만 저장된다.

## 1. 세 학교 기본 회귀

- [x] KCL Nutrition 페이지에서 11개 카드가 모두 보이고 현재 페이지 분석이 완료된다.
- [x] KCL의 Course, Entry Requirements, Korean Academic Requirements, English Requirements, Application Fee, Deadline, Reference, SOP Guideline 값과 항목별 복사가 동작한다.
- [x] SOAS MSc Global Development 페이지에서 11개 카드가 모두 보이고 현재 페이지 분석이 완료된다.
- [x] SOAS Reference에 아래 페이지 원문이 그대로 보이고 복사된다.

```text
References are optional, but can help build a stronger application if you fall below the 2:2 requirement or have non-traditional qualifications.
```

- [x] QMUL Corporate Finance 페이지에서 11개 카드가 모두 보이고 현재 페이지 분석이 완료된다.
- [x] 세 학교 모두 Side Panel에 가로 스크롤, 잘린 버튼, 겹친 문구가 없다.

## 2. 대학 전체 확인한 사항 재사용

1. QMUL 과정의 `University Application Deadline` 카드에서 `확인한 사항 추가`를 누른다.
2. 대학 전체 범위가 `Queen Mary University of London`인지 확인한다.
3. 테스트 값을 저장하고 패널을 닫았다가 다시 연다.
4. 같은 QMUL 과정에서 저장한 확인한 사항이 유지되는지 확인한다.
5. 가능하면 QMUL의 다른 지원 과정 페이지를 열어 같은 대학 메모가 다시 연결되는지 확인한다.

- [x] 저장 직후 카드 안에 확인한 사항이 보인다.
- [x] 패널을 닫았다가 다시 열어도 값과 출처가 유지된다.
- [x] 같은 대학의 다른 과정에서도 University 확인한 사항이 재사용된다.
- [x] 페이지 값과 확인한 사항이 다를 때 두 값이 모두 보이고 페이지 값이 위에 표시된다.

## 3. 학년도 확인과 전환

1. 저장한 확인한 사항에서 `이번 학년도 확인 완료`를 누른다.
2. 패널을 닫았다가 다시 열어 `이번 학년도 확인`과 최근 확인일이 유지되는지 확인한다.
3. 기준을 `2027/28 · 2027년 9월`로 바꾼다.
4. 다시 `2026/27 · 2026년 9월`로 되돌린다.

- [x] `2026/27` 확인 완료 직후 확인 버튼이 사라지고 확인 상태와 최근 확인일이 보인다.
- [x] 패널을 다시 열어도 `2026/27` 확인 기록이 유지된다.
- [x] `2027/28`에서는 값은 남고 `재확인 필요`와 새 확인 버튼이 보인다.
- [x] `2026/27`로 돌아가면 기존 확인 기록과 확인 상태가 복원된다.

## 4. 수정과 삭제

1. 확인 완료한 값을 수정한다.
2. `확인 후 변경` 상태와 재확인 버튼을 확인한다.
3. 삭제 버튼을 눌러 확인 dialog를 연다.
4. 첫 번째에는 취소하고, 두 번째에는 삭제한다.
5. 패널을 닫았다가 다시 연다.

- [x] 수정 후 기존 학년도 확인 기록은 남고 상태는 `확인 후 변경`으로 바뀐다.
- [x] 삭제 dialog에 정확한 항목, 대학 범위, 현재 값과 확인 기록 개수가 보인다.
- [x] 삭제 dialog의 기본 초점은 `취소`에 있다.
- [x] 취소하면 확인한 사항과 확인 기록이 유지된다.
- [x] 삭제하면 해당 항목만 사라지고 다른 항목의 확인한 사항은 유지된다.
- [x] 패널을 다시 열어도 삭제 상태가 유지된다.

## 5. 키보드

마우스를 사용하지 않고 `Tab`, `Shift+Tab`, `Enter` 또는 `Space`, `Escape`로 확인한다.

- [x] `확인한 사항 추가` 버튼에 도달하고 키보드로 dialog를 열 수 있다.
- [x] 추가·수정 dialog 안에서 입력란, 닫기, 취소, 저장으로 이동할 수 있다.
- [x] `Escape`로 추가·수정 dialog를 닫으면 저장되지 않는다.
- [x] `이번 학년도 확인 완료`를 키보드로 실행할 수 있다.
- [x] 삭제 버튼을 키보드로 열면 `취소`에 초점이 있다.
- [x] 삭제 dialog 안에서 초점이 dialog 밖으로 빠지지 않는다.
- [x] `Escape` 또는 취소 버튼으로 닫으면 삭제되지 않는다.

## 6. `0.7.1` 수정 사항 재검증

- [x] `2027/28` 전환 후 값은 유지되고 `재확인 필요`와 `이번 학년도 확인 완료` 버튼이 보인다.
- [x] 현재 학년도 확인 완료 상태의 Application Fee에서 `찾지 못함`, 과정 페이지 미발견 안내, `페이지에는 구체적인 값 없음` 비교 상자가 숨겨진다.
- [x] 화면을 아래로 스크롤하면 `현재 분석 기준` 패널도 함께 위로 사라진다.
