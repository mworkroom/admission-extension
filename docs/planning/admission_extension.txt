# 입학요강 정보 추출 Chrome Extension 프로토타입 기획서

## 1. 프로젝트 개요

대학원 과정 페이지와 관련 지원 안내 페이지에서 입학요강 작성에 필요한 정보를 자동으로 찾아, 별도의 정리된 화면에 표시하는 Chrome Extension을 개발한다.

사용자는 기존처럼 대학 웹사이트를 직접 확인하지만, 페이지 안에서 정보를 하나씩 찾아 Word에 복사하는 과정을 줄인다. 확장 프로그램이 찾은 내용을 항목별로 정리하고, 각 항목을 한 번의 클릭으로 복사할 수 있게 한다.

첫 프로토타입의 목적은 모든 학교의 정보를 완벽하게 추출하는 것이 아니다. 실제 업무에 사용하면서 다음을 확인하는 것이 목적이다.

* 어떤 항목은 대부분의 학교에서 자동 추출되는가
* 어떤 항목은 학교별 별도 페이지나 드롭다운이 필요한가
* 어떤 학교와 항목에서 추출이 반복적으로 실패하는가
* 학교별 예외 규칙이 필요한 부분은 무엇인가

---

## 2. 핵심 목표

### 2.1 업무 중 정보 탐색과 복사 횟수 감소

현재 보고 있는 페이지에서 확인 가능한 정보를 자동으로 찾아 한 화면에 정리한다.

### 2.2 누락 항목 시각화

정보를 찾지 못한 항목을 빈칸으로 명확하게 표시하여, 사용자가 별도로 확인해야 할 내용을 한눈에 파악할 수 있게 한다.

### 2.3 Word에 붙여넣기 쉬운 결과 제공

각 항목에 개별 복사 버튼을 제공하고, 검토가 끝난 전체 내용을 한 번에 복사할 수 있게 한다.

### 2.4 실제 사용을 통한 요구사항 수집

사용자가 값을 수정하거나 다른 페이지에서 정보를 추가한 기록을 남겨, 이후 학교별 예외 처리와 추출 정확도 개선에 활용한다.

---

## 3. 프로토타입 범위

### 포함

* 현재 웹페이지 분석
* 정해진 입학요강 항목 추출
* 추출 결과를 별도 패널에 정리
* 항목별 수정
* 항목별 복사
* 전체 복사
* 추출 실패 항목 표시
* 현재 페이지에서 다시 추출
* 다른 페이지에서 같은 작업 문서에 정보 추가
* 사용자가 수정한 값과 최종 출처 기록
* 학교별·항목별 추출 성공 여부 기록

### 제외

* Word 파일 자동 생성
* Word 템플릿 자동 입력
* Notion 자동 저장
* 전체 대학 사이트 자동 탐색
* 지원서 자동 작성
* 로그인·CAPTCHA 자동 처리
* 모든 학교에 대한 사전 예외 규칙 구축
* AI가 임의로 누락 정보를 추측하여 작성하는 기능

## 4. 추출 대상 항목

### 4.1 University

현재 페이지의 학교명 또는 도메인을 기준으로 추출한다.

예:

```text
King’s College London
University of Manchester
University College London
```

### 4.2 Course

과정 페이지의 제목, 페이지 헤더 또는 구조화된 메타데이터에서 추출한다.

예:

```text
MSc Artificial Intelligence
MA Education
MSc Nutritional Sciences
```

### 4.3 Entry Requirements

Entry Requirements, Entry Qualifications, Academic Requirements 등의 섹션에 포함된 내용을 가능한 한 전체 문맥으로 추출한다.

다음 내용을 포함할 수 있다.

* 요구 학위 등급
* 2:1, 2:2 등 영국 학위 기준
* 지원 가능한 전공
* 지원 불가능한 전공
* 필수 선수과목
* 특정 과목의 최소 성적
* 관련 경력 요건
* 포트폴리오나 실무 경험 요건
* 예외적으로 고려되는 조건
* 지원 전 문의가 필요한 조건

요약하지 않고, 해당 섹션의 문장을 원문에 가깝게 정리한다.

예:

```text
A minimum 2:1 undergraduate degree in computer science or a related quantitative discipline is required.

Applicants should have completed modules in programming, mathematics and statistics.
```

### 4.4 Korean Academic Requirements

한국 학위와 학점 기준을 추출한다.

대부분 국가 선택 드롭다운이나 별도의 International Qualifications 페이지에 있으므로, 첫 프로토타입에서는 다음 방식으로 처리한다.

1. 현재 페이지에 한국 기준이 직접 표시되면 추출
2. 국가 드롭다운이 있으면 `South Korea` 선택 가능 여부 표시
3. 자동 선택이 가능하면 선택 후 결과 추출
4. 자동 선택이 어렵다면 관련 페이지와 버튼 표시
5. 사용자가 직접 확인한 값을 현재 작업에 추가할 수 있게 함

예:

```text
South Korea

A bachelor’s degree with a minimum GPA of 3.3/4.5 or 3.0/4.3.
```

상태 표시 예:

```text
자동 추출 완료
South Korea 선택 필요
별도 국가별 요건 페이지
현재 페이지에서 찾지 못함
```

### 4.5 English Requirements

IELTS 요건을 우선 추출한다.

다음 내용을 구분해 표시한다.

* Overall
* Writing
* Reading
* Listening
* Speaking
* 각 영역 공통 최소 점수
* 대체 시험 안내가 문장에 포함된 경우 해당 문장

예:

```text
IELTS Academic

Overall: 6.5
Writing: 6.0
Reading: 6.0
Listening: 6.0
Speaking: 6.0
```

또는:

```text
Overall 7.0, with no component below 6.5.
```

### 4.6 Tuition Fee

국제학생 기준 학비를 우선 추출한다.

구분이 가능한 경우 다음 내용을 포함한다.

* International tuition fee
* 학년도 또는 Entry Year
* Full-time / Part-time
* 연간 금액인지 전체 과정 금액인지
* 추가 클릭이나 드롭다운 선택 필요 여부

예:

```text
International tuition fee
£35,244 for the 2027/28 academic year
Full-time
```

학비가 접힌 영역에 있을 경우 확장 프로그램이 열 수 있으면 자동으로 열고, 불가능하면 다음 상태를 표시한다.

```text
학비 섹션을 열어야 확인 가능
[현재 페이지에서 다시 찾기]
```

### 4.7 Application Fee

지원 수수료와 결제 조건을 추출한다.

예:

```text
Application fee: £75
The application fee is non-refundable.
```

정보가 없으면 다음과 같이 표시한다.

```text
현재 페이지에서 찾지 못함
```

`지원 수수료 없음`으로 임의 판단하지 않는다.

### 4.8 Application Deadline

다음 내용을 추출한다.

* 정확한 마감일
* 국제학생 별도 마감일
* 라운드별 마감일
* Rolling admissions
* 정원 마감 시 조기 종료 안내
* 비자 신청자를 위한 권장 기한

예:

```text
Application deadline for international applicants:
31 July 2027
```

또는:

```text
There is no formal application deadline. Applications may close when the programme is full.
```

### 4.9 Reference

추천서 또는 추천인 수를 추출한다.

다음 형태를 구분한다.

* One reference
* Two references
* Academic reference
* Professional reference
* 추천서 파일 제출
* 추천인 연락처만 입력
* 지원 후 추천인에게 자동 요청

예:

```text
One academic reference is required.
```

현재 공개 페이지에 없고 지원서 내부에서만 확인 가능한 경우:

```text
현재 페이지에 없음
지원서 내부 확인 필요
```

### 4.10 SOP Guideline

Personal Statement, Statement of Purpose, Supporting Statement 등의 안내를 추출한다.

다음 정보를 포함한다.

* 명칭
* 글자 수 또는 단어 수
* 질문 문항
* 포함해야 할 내용
* 별도 파일 업로드 여부
* 지원서 입력란 작성 여부
* 파일 형식
* 페이지 제한

예:

```text
Personal Statement

Maximum length: 4,000 characters

Explain your academic background, relevant experience, reasons for applying and future career plans.
```

### 4.11 CV 제출 여부

CV 또는 résumé 제출 요건을 추출한다.

상태는 다음 중 하나로 표시한다.

```text
필수
선택
특정 지원자만 필수
현재 페이지에서 확인되지 않음
```

예:

```text
A current CV must be uploaded with the application.
```

## 5. 사용자 화면 구성

확장 프로그램을 누르면 브라우저 오른쪽에 Side Panel을 연다.

### 상단

```text
University of Bristol
MSc Data Science

현재 페이지
https://...

[페이지 다시 분석]
[새 작업 시작]
```

### 항목 카드

각 항목은 개별 카드로 표시한다.

```text
Entry Requirements                         ✓

A strong upper second-class honours degree
in a numerate discipline is required.

Applicants should demonstrate prior study
in mathematics and programming.

[수정] [복사] [원문 위치 보기]
```

찾지 못한 경우:

```text
Application Fee                            —

현재 페이지에서 찾지 못함

[직접 입력]
[다른 페이지에서 가져오기]
[확인 필요로 표시]
```

### 상태 구분

```text
✓ 자동 추출 후 확인 가능
△ 여러 후보 중 선택 필요
✎ 사용자가 수정함
↗ 다른 페이지에서 가져옴
— 찾지 못함
```

색상만으로 상태를 구분하지 않고 아이콘과 문구를 함께 사용한다.

## 6. 복사 기능

### 6.1 항목별 복사

각 항목의 `복사` 버튼을 누르면 내용만 Clipboard에 저장한다.

예:

```text
Overall 6.5, with no component below 6.0.
```

### 6.2 제목 포함 복사

필요한 경우 작은 메뉴에서 제목 포함 여부를 선택한다.

```text
English Language Requirements
IELTS: Overall 6.5, with no component below 6.0.
```

### 6.3 전체 복사

검토가 끝난 항목을 정해진 순서대로 복사한다.

기본 순서:

1. University
2. Course
3. Entry Requirements
4. Korean Academic Requirements
5. English Requirements
6. Tuition Fee
7. Application Fee
8. Application Deadline
9. Reference
10. SOP Guideline
11. CV

출력 예:

```text
University
King’s College London

Course
MSc Artificial Intelligence

Entry Requirements
A minimum high 2:1 undergraduate degree...

Korean Academic Requirements
A bachelor’s degree with...

English Requirements
IELTS overall 7.0, with...

Tuition Fee
£...

Application Fee
Not found

Application Deadline
...

Reference
...

SOP Guideline
...

CV
Required
```

### 6.4 복사 제외

사용자는 각 항목 옆의 체크박스를 해제하여 전체 복사에서 제외할 수 있다.

```text
☑ Entry Requirements
☑ IELTS
☑ Tuition Fee
☐ Application Fee
☑ Deadline
```

## 7. 여러 페이지에서 정보 합치기

하나의 과정에 대해 여러 페이지를 확인할 수 있어야 한다.

예:

1. 학과 페이지에서 기본 정보 추출
2. 학비 페이지로 이동
3. 확장 프로그램에서 `현재 작업에 추가`
4. 국제 학력 페이지로 이동
5. South Korea 정보를 추출해 현재 작업에 추가
6. 지원서 내부에서 Reference와 SOP 정보를 확인
7. 직접 입력하거나 현재 페이지에서 추출
8. 전체 결과 복사

화면 상단에는 현재 작업 대상이 계속 표시된다.

```text
현재 작업
KCL — MSc Artificial Intelligence

[현재 페이지 정보를 이 작업에 추가]
```

새로운 페이지에서 기존 값과 다른 값이 발견되면 자동 덮어쓰기하지 않는다.

```text
기존 IELTS
Overall 6.5, each 6.0

새로 발견한 IELTS
Overall 7.0, each 6.5

[기존 값 유지]
[새 값 사용]
[둘 다 보기]
```

## 8. 수정 및 실패 기록

사용자가 값을 수정하면 다음 내용을 내부적으로 기록한다.

* 학교
* 과정
* 항목
* 원래 추출값
* 최종 수정값
* 현재 URL
* 최초 추출 성공 여부
* 다른 페이지로 이동했는지
* 사용자가 직접 입력했는지
* 확인 날짜

예:

```text
University: University of Manchester
Course: MSc Data Science
Item: Tuition Fee
Initial result: Not found
Final result: £...
Final source: 별도 학비 페이지
Method: 다른 페이지에서 가져오기
```

사용자가 별도의 정리 작업을 하지 않아도, 실제 사용 기록으로 추출 실패 패턴이 쌓여야 한다.

## 9. 추출 방식

첫 프로토타입은 다음 순서로 정보를 찾는다.

### 9.1 페이지 구조 우선

다음과 같은 HTML 요소를 먼저 확인한다.

* Page title
* H1, H2, H3
* Definition list
* Table
* Accordion
* Tabs
* Structured data
* Meta tags

### 9.2 제목과 키워드 탐색

항목별 관련 제목과 단어를 찾는다.

예:

```text
Entry Requirements
Academic Requirements
Entry Qualifications
Admissions Requirements

Tuition Fees
Course Fees
International Fees

English Language Requirements
IELTS

Application Deadline
How to Apply
Application Dates
```

### 9.3 관련 문맥 수집

키워드 한 문장만 가져오지 않고, 해당 제목 아래의 문단·목록·표를 묶어서 수집한다.

### 9.4 AI 정리

수집한 후보 텍스트를 항목별로 분류하고 불필요한 내비게이션 문구를 제거한다.

AI가 원문에 없는 내용을 추측해 추가하지 않으며, 애매한 경우 후보를 여러 개 보여준다.

## 10. 초기 테스트 학교

### 10.1 KCL

거의 모든 정보가 공개되어 있으므로 기본 추출 정확도를 확인하는 기준 학교로 사용한다.

확인 항목:

* Entry Requirements
* Korean Academic Requirements
* IELTS
* Tuition Fee
* Application Fee
* Deadline
* Reference
* SOP
* CV

특히 학비가 클릭 후 표시되는 구조를 테스트한다.

### 10.2 정보가 여러 페이지에 흩어진 학교

학비, IELTS, Deadline이 서로 다른 페이지에 있는 학교를 선정한다.

테스트 목적:

* 여러 페이지의 정보를 하나의 과정에 합치기
* 학교 공통 페이지와 과정별 페이지 구분
* 기존 값과 새 값 충돌 처리

### 10.3 지원서 내부 확인이 필요한 학교

Reference, SOP, CV 정보가 공개 페이지에 없는 학교를 선정한다.

테스트 목적:

* 직접 입력
* 지원서 내부 페이지에서 추출
* 확인 완료된 값을 현재 작업에 추가
* 추출하지 못한 상태를 명확하게 표시

초기 학교 수는 3개로 시작하고, 실제 업무 중 사용하는 학교를 순차적으로 추가한다.

## 11. 프로토타입 성공 기준

다음 조건을 만족하면 첫 프로토타입은 성공으로 판단한다.

* 확장 프로그램 클릭 후 Side Panel이 열린다.
* University와 Course를 높은 확률로 인식한다.
* KCL 과정 페이지에서 공개 정보 대부분을 추출한다.
* 항목별 결과가 정해진 순서로 정리된다.
* 각 항목을 한 번의 클릭으로 복사할 수 있다.
* 전체 결과를 한 번에 복사할 수 있다.
* 잘못 추출된 값을 직접 수정할 수 있다.
* 찾지 못한 항목이 명확하게 표시된다.
* 다른 페이지의 정보를 기존 작업에 추가할 수 있다.
* 사용자 수정과 추출 실패 기록이 남는다.
* 실제 입학요강 작업 중 기존 복붙 횟수가 줄어든다.

## 12. 프로토타입 이후 개선 우선순위

실제 사용 기록을 기준으로 다음 순서로 개선한다.

### 1순위

자주 추출에 실패하지만 공개 페이지에는 존재하는 항목

### 2순위

별도 페이지 이동이 반복되는 학교와 항목

### 3순위

드롭다운 선택 후 표시되는 Korean Academic Requirements와 Tuition Fee

### 4순위

시즌마다 한 번만 확인하면 되는 학교 공통 정보

* SOP Guideline
* Reference
* CV
* Application Fee

### 5순위

학교별 예외 규칙

예:

```text
이 학교의 Tuition은 별도 Fee Lookup에서 확인
이 학교의 IELTS는 Band B 페이지 참조
이 학교의 Deadline은 과정 페이지가 아니라 중앙 일정 페이지 참조
```

## 14. 핵심 원칙

1. 완벽한 추출보다 복사 노동 감소를 우선한다.
2. 찾지 못한 정보는 추측하지 않고 명확한 빈칸으로 표시한다.
3. 사용자는 Word 문서 편집을 직접 수행한다.
4. 별도의 사전 자료 조사 없이 실제 업무를 통해 데이터를 모은다.
5. 일반 규칙으로 처리되지 않는 부분만 학교별 예외 규칙으로 추가한다.
6. 사용자가 정보를 수정하는 행동이 다음 개발 단계의 자료가 되게 한다.
7. 자동화로 인해 원문 확인이 어려워지지 않도록 모든 항목에 출처를 남긴다.
8. 첫 버전은 KCL에서 잘 작동하는 것을 기준으로 삼되, KCL에만 맞춘 구조로 만들지 않는다.
