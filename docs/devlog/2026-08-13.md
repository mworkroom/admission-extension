# 2026-08-13 Admission Extension Development Log

## Work Summary

CSV에 정리된 13개 학교의 실제 금액 문맥 조사 결과를 바탕으로, 페이지에서 가장 큰 금액을 학비로 선택하던 식의 크기 추정을 사용하지 않고 금액의 의미와 적용 기준을 먼저 판정하는 범용 학비 수집기를 구현했다.

## Work Completed

- 페이지의 GBP 금액을 학비, 지원비, 보증금, 장학금·할인, 기타 비용으로 분류하는 공통 후보 수집 단계를 추가했다.
- 학비 후보에 가까운 학년도, 입학 시기, Full-time·Part-time, Home·International 문맥을 연결했다.
- 금액 주변에 학년도가 없을 때는 페이지 전체에서 학년도가 하나만 확인된 경우에만 그 학년도를 상속하도록 했다.
- 여러 학년도가 함께 표시된 페이지에서는 학년도를 임의로 상속하지 않고 사용자 확인 상태를 유지하도록 했다.
- 연결된 일반 학비 페이지에서도 보증금, 장학금, 생활비 등의 금액을 학비 후보에서 제외하고 현재 학년도 후보만 남기도록 보강했다.
- 현재 기준과 정확히 일치하는 학비 후보가 학년도 없는 후보보다 우선되도록 parser의 후보 구체성 비교를 추가했다.
- Manchester, UCL, Edinburgh, Leeds, Warwick, Birmingham, Nottingham, Bristol, York, Loughborough, Sheffield, Southampton, Exeter의 금액 문맥을 재현한 회귀 테스트를 추가했다.
- 단일 학년도 상속과 복수 학년도 비확정 동작을 별도 테스트로 고정했다.

## Decisions

- 금액의 크기는 학비 판정 조건으로 사용하지 않는다. 전체 장학 재원, 시설 투자비, 생활비, 보증금, 졸업생 연봉이 학비보다 크거나 작을 수 있기 때문이다.
- 금액은 먼저 주변 문맥으로 유형을 분류하고, 학비로 분류된 후보에만 학년도·입학 시기·수학 형태·fee status 조건을 적용한다.
- 페이지의 학년도는 사용자 설정값으로 덮어쓰지 않는다. 실제 페이지에서 단일 학년도가 확인된 경우에만 보조 근거로 사용한다.
- Edinburgh와 Warwick처럼 공식 연결 학비표가 있는 구조는 기존 링크 추적과 과정 코드 필터를 유지하고 공통 금액 분류 안전장치만 추가한다.

## Current Status

- 13개 학교 금액 유형 회귀군과 기존 generic reader·course parser 집중 테스트가 통과했다.
- `npm.cmd run check`로 전체 문법 검사와 92개 테스트가 모두 통과했다.
- 학비·지원비·보증금·장학금·기타 분류 결과는 snapshot의 `moneyCandidates`에 보존되며, UI의 Tuition Fee에는 현재 기준과 일치하는 학비만 전달된다.
- 실제 설치된 Chrome 확장 프로그램에서의 최종 확인은 최신 로컬 확장을 다시 로드한 뒤 진행해야 한다.
- 변경은 로컬에만 있으며 커밋하거나 배포하지 않았다.

## Next Steps

- Chrome 확장을 다시 로드하고 우선 Southampton, Birmingham, Loughborough에서 기타 금액이 학비로 섞이지 않는지 확인한다.
- 실제 페이지에서 새로운 오분류가 발견되면 학교명 예외가 아니라 금액 문맥 분류 계열을 회귀 사례로 추가한다.
