## Decisions - Phase 4 P4-6 자유 형식 문제 기록

- `여러 마감일`, `일부 추출`, `잘못된 값` 같은 카테고리를 미리 고정하지 않는다. 자유 기록이 실제로 반복된 뒤 Phase 5의 구조화 분류나 parser 개선 후보로 승격한다.
- 문제 기록은 11개 항목의 추출값, 확인 상태와 공통 메모를 바꾸지 않는 독립 데이터로 유지한다.
- 활성 작업 시작을 문제 기록의 선행 조건으로 두지 않는다. 현장에서 예외를 발견한 즉시 남기는 흐름이 데이터 수집 목적에 더 맞기 때문이다.
- 문제 삭제도 감사 이력에서는 제거하지 않는다. 목록 정리와 실사용 문제 데이터 보존을 분리한다.
