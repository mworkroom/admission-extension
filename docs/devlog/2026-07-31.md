## Decisions - GitHub 초기 게시

- 계획서, 명세, QA 체크리스트와 개발 로그는 프로젝트 의사결정과 검증 근거이므로 소스와 함께 공개한다.
- 테스트 fixture는 공개 대학 페이지에서 추출한 최소 검증 데이터이고 인증정보나 개인 데이터가 없어 포함한다.
- Git 작성자 이메일은 전역 사용자 설정을 바꾸지 않고 이 저장소에만 적용되는 `noreply` 주소를 사용한다.
- 원격의 `index.html`은 Chrome Extension 실행에 사용되지 않는 임시 Hello World 파일이므로 실제 앱 게시 커밋에서 제거한다.
- 초기 저장소이므로 별도 기능 브랜치나 PR을 만들지 않고 원격 기본 브랜치 `main`에 직접 게시한다.
