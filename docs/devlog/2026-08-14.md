# 2026-08-14 Admission Extension Development Log

## Work Summary

자동 추출이 놓친 정보를 실제 업무 중 수동 기록할 때 자유 형식의 `한 줄 요약`을 반복 작성하고, 저장 결과의 상세 내용을 다시 펼쳐야 하는 불편을 줄였다. 지정된 항목은 업무 판단에 맞는 고정 선택지를 사용하고, 수동 기록이 있으면 해당 카드에서는 자동 추출 안내 대신 사용자가 기록한 정보만 바로 보이도록 변경했다.

## Work Completed

- Korean Equivalent, IELTS, Reference, SOP Guideline, CV에는 `별도 페이지`, `지원서 내부 확인`, `못 찾음` 선택지를 추가했다.
- Application Fee에는 `No application fee`, `못 찾음`, Application Deadline에는 `Rolling basis`, `Staged admission` 선택지를 추가했다.
- Entry Requirements, Tuition Fee, 대학 전체 메모처럼 선택지가 정의되지 않은 기존 입력 화면은 자유 입력을 유지해 범위를 임의로 확장하지 않았다.
- `출처 이름` 입력을 제거하고 저장된 출처 URL은 항상 `출처` 링크로 표시했다.
- 수동 기록은 선택값, 상세 설명, 출처, 확인 상태 순서로 접힘 없이 모두 표시하고, 확인일은 `8/14/26 확인됨` 형식으로 상태와 함께 표시했다.
- 수동 기록이 있는 카드에서는 자동 추출 값, 실패 안내, 상태 아이콘, 원문·복사 액션을 숨겨 두 정보가 섞이지 않게 했다.
- 항목별 선택지, 입력 폼, 펼침 표시, 자동 분석 숨김에 대한 회귀 테스트를 추가하고 UI 하네스를 현재 화면 계약에 맞췄다.

## Decisions

- 드롭다운 선택값이 수동 기록의 핵심 내용이므로 빈 저장은 허용하지 않고 명시적 선택을 유지했다. 첫 선택지를 자동 지정하지 않아 실수로 잘못된 상태를 저장하지 않게 했다.
- 기존 schema 2 레코드와 `sourceLabel` 값은 삭제하거나 강제 변환하지 않았다. 새 UI에서는 출처 이름을 받거나 표시하지 않지만 기존 로컬 저장값은 계속 읽을 수 있다.
- 수동 기록이 존재하면 그 항목에서는 사용자 입력을 표시 우선순위로 삼았다. 자동 분석 결과는 삭제하지 않고 화면에서만 숨겨, 수동 기록을 삭제하면 다시 나타나게 했다.
