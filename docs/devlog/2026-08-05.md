# 2026-08-05 Admission Extension Development Log

## Work Summary

실사용 피드백을 바탕으로 앱의 목적을 전체 입학요강 자동화가 아니라 공개 페이지의 핵심 정보, 반복 예외, 앱 문제를 빠르게 확인하는 반자동 작업 보조로 재정의했다. Word 문서를 실제 작업 기준으로 유지하면서 Side Panel의 인지부하를 줄이는 방향으로 UI와 저장 구조를 개편했다.

## Work Completed

- 활성 과정 작업, 직접 입력, 실사용 활동 로그, 활성 작업 JSON·CSV UI와 실행 모듈을 제거했다. 기존 브라우저의 관련 저장 키를 삭제하는 동작은 추가하지 않았다.
- University와 Course를 상단 작업 문맥으로 옮기고, Entry Requirements·Tuition Fee·Application Fee·IELTS 및 메모·오류 항목만 기본 화면에 표시했다. 나머지 정상 항목은 접힌 영역에 유지했다.
- 복사 버튼을 Entry Requirements, Tuition Fee, Application Fee에만 제한하고 버튼명을 `복사`로 통일했다.
- 확인한 사항 schema를 2로 올려 대학 전체·항목별 한 줄 요약, 선택 상세·출처, 확인/미확인 상태, 학년도별 명시적 확인일을 지원했다. schema 1 저장값은 값과 기존 확인 기록을 보존해 변환한다.
- 문제 기록 schema를 2로 올려 활성 작업 로그와 분리하고 미해결·해결됨 상태, JSON 내보내기를 추가했다. 기존 schema 1 기록은 미해결 상태로 변환한다.
- 패널 최초 열기, 탭 전환과 같은 탭의 URL 변경에서 자동 분석하고 분석 실패 또는 기준 변경 상태에서만 `다시 분석`을 표시하도록 했다.
- 문제 기록과 상담 위젯 설정을 상단 도구 dialog로 이동했다.
- 확장 버전을 `0.15.0`, UI 저장 버전을 4로 갱신했다.

## Decisions

- Notion University DB는 공통 패턴 분석에만 사용하고 확장 프로그램과 동기화하지 않는다. 메모는 계속 브라우저 로컬에 수동으로 관리한다.
- 확인한 사항은 다음 업무의 판단 보조 지식이고, 문제 기록은 앱 개선 피드백이므로 저장소와 UI를 분리한다.
- 메모 수정만으로 확인일을 갱신하지 않는다. 확인 상태와 날짜를 명시적으로 선택했을 때만 해당 학년도 확인 기록을 갱신한다.
- 현재 학년도 확인 기록이 없으면 경과 기간과 관계없이 `다시 확인`으로 표시한다.
- 일반 HTTPS 페이지 분석과 기존 정밀 adapter는 유지하되 72개 대학별 전용 규칙을 선행 구축하지 않는다.
